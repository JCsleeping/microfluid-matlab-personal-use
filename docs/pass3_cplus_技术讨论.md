## 1. 问题背景

DNAPL 饱和帧中，粉色区域内散布暗色小点（气泡/杂质/光学伪影）。这些暗点在 Lab a\* 通道中值偏低，被 Pass 1 GMM 误判为"非 DNAPL"，导致 mask 出现空洞。

当前 Pass 2（形态学重建，r=3）只能填充直径 <6px 的孤立暗点。更大或更密集的暗点簇无法被重建消除。

## 2. C+ 方案设计

在 Pass 2 之后增加 Pass 3，对剩余背景碎片做 5 级 reject-first 判定：

| # | 判据 | 拒绝条件 | 目的 |
|---|------|---------|------|
| 1 | 面积 | > 500 px | 排除大水通道 |
| 2 | DNAPL 周界比例 | < 70% | 碎片不被 DNAPL 包围 |
| 3 | L\* 绝对暗度 | ≥ 65 | 亮碎片是水袋不是暗点 |
| 4 | 环带相对暗度 ΔL | ≤ 10 | 不比周围更暗 |
| 5 | 入口连通性 | 连通入口水 | 属于水流路径 |

全部通过才回收为 DNAPL。另外对 `too_large` 碎片做 L\* 子分割，提取暗像素子碎片独立评估。

## 4. 失败原因分析

### 4.1 测试图不存在暗点遗漏问题

Pass 1 GMM 已正确捕获所有暗像素。非 DNAPL 区域 **L\* 最小值 = 72**，零暗像素。C+ 的暗点回收功能根本没有被触发。

### 4.2 Old Pass 3 是过度分割

Old Pass 3 回收的 44 个碎片全部是 L\*=76-83 的亮水袋。C+ 正确拒绝了它们——但这体现的是"防误回收"价值，不是"暗点回收"价值。

### 4.3 bwconncomp 连通域过大

暗点如果存在，会通过 8-连通与周围亮水相连成大连通域（>500px），导致：

- 整体面积超阈值 → `too_large`
- 整体 L\* 被亮像素拉高 → `too_bright`

子分割（提取 L\*<65 的暗像素子碎片）在此图上回收 0 个，因为不存在 L\*<65 的非 DNAPL 像素。

### 4.4 测试环境问题

- 测试脚本脱离 main pipeline，`fd_image` 来自不同实验，flow_domain 提取不稳定
- `kernel_size` 硬编码，照度校正不充分（右侧偏亮）

## 5. 核心教训

1. **Pass 1 GMM 在此实验条件下已经足够好** — 暗点都被正确识别为 DNAPL
2. **Pass 3 的真正价值是防过度分割**（阻止亮水袋被错误回收），而非暗点恢复
3. **暗点问题可能只在特定实验条件下出现**（如 06 LNAPL-4ul 饱和帧），未在此轮验证
4. **独立测试脚本的局限性**：脱离 pipeline 上下文会引入 flow_domain/illumination 的偏差

## 6. 建议后续方向

- **短期**：保持 Pass 1 + Pass 2（v3.0），增大 `hole_fill_radius`（3→5）可能更简单有效
- **中期**：在暗点密集的实验（06 LNAPL-4ul 饱和帧）上验证 C+ 是否有价值
- **长期**：考虑三类 GMM（DNAPL / 水 / 暗杂质）替代后验修正
